# Counterexample: principal hardness up-sets do not suffice

14 September 2026. **Red-team record.** This note prevents an over-strong simplification of [`DOMINANCE_UPSET_HALL.md`](DOMINANCE_UPSET_HALL.md).

The dominance-upset theorem proves that a minimum Hall witness can be chosen as an up-set in

```text
(q,c,P) >=_H (q',c',P')
iff q>=q', c<=c', P>=P'.
```

It does **not** follow that one principal up-set generated by a single type is enough.

## Small explicit counterexample

Take three labelled types, each with multiplicity one:

```text
A = (q,c,P) = (1,1,2),
B = (q,c,P) = (1,2,1),
C = (q,c,P) = (2,2,1).
```

The source/target intervals are

```text
I_A=[1,1],  J_A=[1,2],
I_B=[1,2],  J_B=[1,3],
I_C=[2,2],  J_C=[2,3].
```

Off the deleted diagonal the directed compatibilities are

```text
A -> B,
B -> A,
B -> C,
C -> A,
C -> B,
```

with no arc `A -> C`.

The hardness poset is a `V`:

```text
A >=_H B,
C >=_H B,
```

while `A` and `C` are incomparable.

Hence the nonempty principal up-sets are

```text
up(A) = {A},
up(C) = {C},
up(B) = {A,B,C}.
```

## Hall margins

For the labelled Hall margin

```text
F(W)=sum_w min(P_w,d_W(w)) - sum_{u in W} q_u,
```

we obtain

```text
F({A})       = 0,
F({C})       = 0,
F({A,B,C})   = 0.
```

Thus every principal hardness up-set passes.

But the two-generator up-set

```text
W={A,C}
```

has target capacity

```text
target A: 1   (from C),
target B: 1   (from A and C, capped at P_B=1),
target C: 0,
```

so

```text
R(W)=2,
L(W)=q_A+q_C=3,
F(W)=2-3=-1.
```

Therefore the target-flow Hall condition fails although every principal up-set is nondeficient.

The full set has

```text
F({A,B,C})=0,
```

so this is a genuine proper-subset Hall obstruction rather than a total-capacity failure.

## Consequence

A valid further compression must allow **multiple incomparable generators**. In particular, none of the following is justified in general:

```text
"check one type only",
"check one principal hardness up-set only",
"every deficient up-set has a deficient principal sub-up-set".
```

The running principal-upset frontier pilot is therefore reconnaissance: it measures practical reach on the Murty-Simon profiles but cannot replace the exact type-level max-flow theorem.

## Stronger warning

A separate small search also finds a four-type profile whose only deficient hardness up-set needs three incomparable generators:

```text
(1,1,0),
(1,2,2),
(2,2,2),
(2,3,3).
```

The unique deficient up-set in that example is the three-generator set represented by mask `1101` in the displayed order, with Hall margin `-1`.

Thus generator number is not bounded by two even in very small canonical-shaped interval profiles.

External mathematical review and novelty assessment remain open. This note is a counterexample record, not a Murty-Simon closure claim.
