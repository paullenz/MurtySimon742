# Exact staircase form of the dominant BC transport slice

9 September 2026. Research note inside the candidate selected/residual framework. This is an exact reformulation of the stripped fractional transport slice, **not** an unrestricted Murty–Simon theorem.

## 1. Two-dimensional order

Retain the inherited source-state domain, source threshold constraints, label-state domain, exact residual budget and total incidence balance, but omit the edge condition `s <= rho` from source-label compatibility. The remaining two compatibility conditions are

\[
d:=R+s\le \alpha:=\rho+q-1,
\]

and

\[
h:=R+x\ge \beta:=q+p.
\]

Equivalently, with

\[
Y=(d,-h),\qquad X=(\alpha,-\beta),
\]

compatibility is the product order

\[
Y\le X.
\]

The label incidence mass and source incidence capacity are

\[
\mu_{R,x,g}=n_g x L_{g,R,x},
\qquad
\nu_{q,p,k}=n_k q W_{k,q,p}.
\]

By the finite monotone-coupling lemma in `MONOTONE_COUPLING_REDUCTION.md`, the BC transport exists exactly when total mass agrees and every upper-set inequality holds.

## 2. Every 2D upper set is a staircase

On the integer `(d,-h)` grid, an upper set is determined by a nonincreasing threshold in the second coordinate. In `(d,h)` coordinates this is equivalently a nondecreasing extended-integer staircase function

\[
H(d).
\]

The corresponding upper set is

\[
A_H=\{(d,h): h\le H(d)\}.
\]

The monotonicity condition is

\[
d_1\le d_2\quad\Longrightarrow\quad H(d_1)\le H(d_2).
\]

Values below the supported `h` range encode an empty vertical section and values above it encode a full section.

Therefore the complete BC Hall family is exactly the family of inequalities

\[
\boxed{
\sum_{g,R,x:\ R+x\le H(R+s)} n_g x L_{g,R,x}
\;\le\;
\sum_{k,q,p:\ q+p\le H(\rho_k+q-1)} n_k q W_{k,q,p}
}
\tag{BC-H}
\]

for every nondecreasing staircase `H`, together with total incidence equality.

No `Z` variables are needed.

## 3. Finite antichain description

A finite staircase can be encoded by its minimal generator antichain

\[
(d_1,h_1),\ldots,(d_j,h_j),
\]

with

\[
d_1<d_2<\cdots<d_j,
\qquad
h_1<h_2<\cdots<h_j.
\]

The upper set is the union of the orthants generated by these points. Thus `j` is the natural staircase complexity.

In the preserved n=30 equality-frontier laboratory, the exact `BC` compatibility ablation rejects six of the seven residual-budget hard states. The explicit two-dimensional ambient-upper-set generator reproduces exactly those same six rejections; the one surviving state is the same state that requires the omitted `s <= rho` coordinate. The proof-active 2D upper sets observed in that run have generator size at most 7. This is finite evidence only, not a universal seven-step theorem.

## 4. Why this is a useful symbolic target

The previous incidence LP can now be replaced, on the dominant six-state slice, by a single universal statement about the weighted cumulative masses on the two sides of (BC-H). Any future general proof can therefore aim to show that graph-derived source constraints and the exact residual-degree mass force (BC-H) for every nondecreasing staircase `H`, or force enough integrated consequences of (BC-H) to contradict positive surplus.

Weighted sums of staircase inequalities are equivalent to testing increasing step potentials on `(d,-h)`. This gives two equivalent symbolic viewpoints:

- **staircase / majorization:** prove (BC-H) directly for all monotone paths;
- **potential / dual:** identify a simple increasing function whose expectation under label incidence exceeds what source incidence can support.

The one exceptional n=30 state indicates that the full argument may need a separate three-dimensional correction using the first coordinate `s <= rho`, rather than burdening the dominant 2D argument with that coordinate everywhere.
