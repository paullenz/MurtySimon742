# Unmatched row-singleton cover reduction

18 September 2026. Research directed by Paul Lenz; derivation and finite regression by ChatGPT/Geeps.

**Status: internal candidate structural reduction; not promoted.** This continues `NEAR_FULL_TIGHT_MATCHING_NORMAL_FORM.md` and studies the `p` rooted B-edges joining one unmatched vertex to the `p` tight fibres.

Let the tight pairs be `P_1,...,P_p`, with `p>=3`, and let `y in U` be unmatched. Write `q_i in P_i` for the unique endpoint adjacent to `y`.

Define a graph `K_y` on the coordinate set `[p]` by

`ij in E(K_y)  iff  q_i q_j in E(G)`.

Thus `K_y` records the graph induced by the matched endpoints selected by the transversal `y`.

Let `c(y)` be the partial Boolean code of `y`, and use `bar(c(y))` as a common origin in the Boolean cube.

---

## 1. Exact row-singleton form of the P--U constraints

For the physical edge `y q_i`, `NEAR_FULL_TIGHT_MATCHING_NORMAL_FORM.md` gives the two possible A-witness codes

`alpha(q_i)` and `beta_i(y)`.

Relative to the origin `bar(c(y))`, these have a simple description.

Let

`A_i = { j != i : ij notin E(K_y) }`

be the open non-neighbour set of coordinate `i` in `K_y`.

Then

> `alpha(q_i) = bar(c(y)) xor A_i`,                    (1.1)

because in a fibre `j!=i` the code `alpha(q_i)` differs from `bar(c(y))` exactly when `q_i` is nonadjacent to the selected endpoint `q_j`.

Also

> `beta_i(y) = bar(c(y)) xor {i}`.                    (1.2)

Therefore, after translating the Boolean cube by the fixed vector `bar(c(y))`, the `p` selected-witness constraints generated by the P--U edges at `y` become exactly

> `{ A_i, {i} }`, `i=1,...,p`.                        (1.3)

Call this `p`-edge graph on subset-codes the **row-singleton graph** `Psi(K_y)`.

Hence any realised A-code support must contain a vertex cover of `Psi(K_y)`.

This reduction depends only on the graph `K_y`; the ambient 2-lift signing has disappeared from these `p` local constraints.

---

## 2. One-code cover is completely classified

The cheapest possible behaviour is

`tau(Psi(K_y))=1`.

This has an exact classification.

> **ROW-SINGLETON ONE-CODE THEOREM.** For `p>=3`,
>
> `tau(Psi(K))=1`
>
> if and only if
>
> `K=K_p`
>
> or
>
> `K=K_{p-1} dotcup K_1`.

### Proof

Suppose one subset-code `C` meets every edge

`{A_i,{i}}`.

Thus for every `i`, either

`C=A_i`

or

`C={i}`.

The singleton vertices `{i}` are pairwise distinct, so `C={i}` can hold for at most one index.

### Case 1: C is not a singleton used by one edge

Then `C=A_i` for every `i`.

But `i notin A_i` for every `i`. Since the same set `C` avoids every coordinate, `C=emptyset`. Therefore every `A_i` is empty, so every coordinate is adjacent to every other coordinate:

`K=K_p`.

Conversely, if `K=K_p`, every `A_i=emptyset`, and the empty code covers all `p` edges.

### Case 2: C={j}

For every `i!=j`, the edge indexed by `i` cannot be covered through its singleton endpoint `{i}`, so necessarily

`A_i={j}`.

Thus every `i!=j` is adjacent to every vertex except `j`. By symmetry, `j` is nonadjacent to every `i!=j`. Therefore

`K-j=K_{p-1}`

and `j` is isolated:

`K=K_{p-1} dotcup K_1`.

Conversely, in this graph every `A_i={j}` for `i!=j`, while the `j`-indexed edge is met by its singleton endpoint `{j}`. So `{j}` covers every edge.

This proves the classification.

## 3. Antipode meaning of the two one-code cases

Let `q_i'` be the tight mate of `q_i`.

The partial-code condition for `y` to be antipodal to the matched endpoint `q_i'` is

`c(y)=alpha(q_i')`.

A direct fibre check gives:

> `c(y)=alpha(q_i')  iff  i is a universal vertex of K_y`.      (3.1)

Indeed, outside fibre `i`, the non-neighbour selected by `alpha(q_i')` equals `q_j` exactly when `q_i q_j` is an edge.

This makes the one-code classification strategically meaningful.

### Complete selected-endpoint graph

If

`K_y=K_p`,

then every coordinate is universal. Hence every tight mate `q_i'` is **partial-code eligible** to be an antipode partner of `y`.

The P--U selected-witness constraints are maximally cheap, but the root contains the large clique

`{y,q_1,...,q_p}`

inside `G[B]`. Any eventual closure of this case should price that clique through edge criticality and the antipode error system rather than through support alone.

### Clique plus one isolate

If

`K_y=K_{p-1} dotcup K_1`,

there is no universal coordinate for `p>=3`. Consequently **no matched endpoint is partial-code eligible to be antipodal to `y`**.

But in the near-full `p>=2` branch the no-private-foot theorem says that `y` must have an antipode partner. Therefore its partner must lie in `U`. By the complementary-code theorem,

> there exists `z in U` antipodal to `y` with
>
> `c(z)=bar(c(y))`.                                    (3.2)

So the second maximally cheap local cover pattern forces an actual complementary unmatched antipode.

This is a useful dichotomy: one-code efficiency is not generic. It is tied either to a large selected-endpoint clique or to a forced U--U complementary antipode.

## 4. Finite regression

The companion checker

`check_unmatched_row_singleton_cover.py`

enumerates every NetworkX graph-atlas graph of exact order `p=3,...,7`, constructs `Psi(K)`, solves its vertex-cover number exactly by brute force, and verifies the one-code theorem.

For each `p=3,...,7`, exactly two unlabelled graphs have `tau(Psi)=1`:

- `K_p`;
- `K_{p-1} dotcup K_1`.

No other one-code cases occur.

The finite scan is regression evidence only. The classification proof above is the mathematical basis.
